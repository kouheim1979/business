# Business Toolkit

仕事を整理するための無料・ログイン不要のブラウザーツール集です。日本語・スマートフォン対応。外部APIや追加ライブラリは不要です。

## ツール一覧

| ツール | 内容 |
| --- | --- |
| DISC簡易診断 | 16問の5段階回答でD（推進）、I（交流）、S（協調）、C（分析）の傾向を表示。タイプ別の活かし方も紹介 |
| SWOT分析 | 強み・弱み・機会・脅威を入力。まとめてコピー |\n| MECE整理ツール | テーマ・分類軸・境界・具体例を入力してロジックツリーを作成。重複の機械的検出と網羅性の自己チェックを表示 |
| 優先順位マトリクス | 重要度・緊急度を5段階で登録。4象限に自動分類、完了管理・一覧コピー |
| 1on1質問メーカー | 進捗・課題・成長・連携・働きやすさのテーマごとに質問を提案。面談メモを保存 |
| 会議アジェンダ | 会議名・目的・議題・持ち時間を記録。配分の超過チェックとテキストのコピー |

## 起動・公開

- トップページ `index.html` は `business.html` へ案内します。
- アプリ本体は `business.html`、スタイルは `business.css`、動作は `business.js` と `mece.js`。
- ローカル確認：`python3 -m http.server 8000` を実行して `http://localhost:8000/` を開きます。
- GitHub Pagesを使う場合は、Repository Settings → Pages → Build and deployment から、`main` ブランチのルート `/ (root)` を指定してください。公開設定の反映はGitHub側で行われます。

### 既存のゲームについて

このリポジトリに元から入っていた「都道府県ドラフトバトル」は削除していません。`draft.html` から利用できます。従来のゲームファイル（`app.js`、`data.js` など）は保持し、従来のREADMEは `DRAFT_README.md` に移しました。

## 保存とプライバシー

入力内容はブラウザーの `localStorage` に保存されます。外部送信・アカウント登録・分析トラッキングは実装していません。ブラウザーのデータを消すと入力も失われ、端末間の同期もありません。職場の機密情報は職場の方針に従って入力してください。

MECEの重複チェックは同一・類似表記の完全一致に近い判定だけで、概念上の重複や未知の漏れを自動的に証明するものではありません。\n\n**DISC簡易診断は公式のDISC評価ではなく、独自の自己理解用チェックです。** 科学的に検証された性格検査・能力測定ではなく、採用、人事評価、メンタルヘルス判断などには使用しないでください。結果は回答時点の自己評価に依存します。

## 技術

静的HTML/CSS/JavaScriptのみで動作します。ビルド不要、APIキー不要。アクセシブルなフォーム、モバイル対応、モーション低減設定への配慮があります。
