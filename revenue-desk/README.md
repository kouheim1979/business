# Revenue Desk — 収益化サイト管理アプリ

独立して運営する複数の収益化サイトを管理する、スマホ対応のシングルHTMLアプリです。

## 主な機能

- サイトごとの公開URL、運用状況、広告審査、月間収益目標
- 月間の収益・運営費用・利益、過去6か月の推移
- AdSense・アフィリエイト・その他の収入や支出の記録
- サイト別の優先タスク、期限、完了状況
- 暗号化されたJSONバックアップの書き出しと復元、平文初期設定JSONの取り込み
- CSVでの収支出力（**CSVは暗号化されません**）

## 使い方

1. [index.html](./index.html) を HTTPS のWebサーバー、またはGitHub Pages上で開きます。
2. 8文字以上のパスフレーズを入力し、暗号化された保存領域を作成します。
3. 「サイト管理」からサイトを追加するか、設定画面で初期設定JSONを取り込みます。
4. 「収益・費用」で収支を入力し、「タスク管理」でTODOを管理します。
5. 定期的に「データ管理」から暗号化JSONを保存してください。

## データとプライバシー

- **ソースコードには運営サイトの実名・URL・収益情報を含めていません**。初期状態は空です。
- 初期設定JSONは個人的に保持し、この公開リポジトリへコミットしないでください。
- 入力データはブラウザの localStorage 上に PBKDF2-SHA-256（220,000回）と AES-GCM で暗号化して保存します。暗号化はブラウザの Web Crypto API を使用します。
- パスフレーズ自体は保存されません。忘れた場合は復元できません。
- 外部API・トラッキング・広告SDKは使用せず、収益やアクセス数の自動取得はしていません。
- **GitHub Pagesは公開サイトであり、ここへのアクセスはユーザー認証で保護されません。** 暗号化されるのは管理内容であり、ソースコード自体は誰でも見ることができます。
- **同じGitHub Pagesのオリジンには別のアプリも存在する可能性があります。** オリジン上の他のスクリプト、悪意あるブラウザ拡張、端末自体の侵害まで防ぐものではありません。
- 初期設定JSONやCSVは**平文**です。第三者に共有しないでください。
- ブラウザのデータ削除、プライベートモード、端末変更では保存内容が失われる可能性があります。
- パスフレーズの強度が暗号化の安全性に影響します。長く推測しにくいものを使ってください。

## 初期設定JSON形式

登録情報は公開コードに含めません。取り込みデータは次の形式です。

    {
      "version": 1,
      "sites": [
        {
          "id": "site-a",
          "name": "サイトA",
          "url": "https://example.org/",
          "platform": "独立サイト",
          "status": "active",
          "ads": "review",
          "goal": 0,
          "memo": ""
        }
      ],
      "entries": [],
      "tasks": []
    }

運用状況: \`active\`, \`building\`, \`paused\`。広告審査: \`none\`, \`review\`, \`approved\`, \`rejected\`, \`na\`。

### 注意

サイト・広告の状況、収益、アクセス解析を自動で取得するものではなく、**手動で記録する管理台帳**です。AdSense審査状況の初期値は最新の正式な通知と照合してください。
